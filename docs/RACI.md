# RACI – StadtPilot 360°

| Arbeitspaket | Haydar / Projektleitung | Sponsor / Führungskraft | Fachämter / Expert:innen | Gremien / Beteiligte |
|---|---:|---:|---:|---:|
| Ausschreibung und Bedarf analysieren | R | A | C | I |
| Zielbild und Produktstruktur definieren | R | A | C | I |

| Ergebnis präsentieren | R | A | C | I |
| Überführung in einen realen Pilot prüfen | R | A | C | I |

## Legende

- **R – Responsible:** setzt das Arbeitspaket operativ um.
- **A – Accountable:** trägt die finale Verantwortung bzw. gibt frei.
- **C – Consulted:** wird fachlich einbezogen.
- **I – Informed:** wird transparent informiert.

Das Modell ist eine Demonstration der Rollenlogik und keine Aussage über die tatsächliche Aufbauorganisation der Stadt Herrenberg.
